# Patty the Assistant

A super-minimal profile site for Patty, Pat Cullen's technical assistant.

Built with Next.js 16, React 19, Tailwind CSS v4, and Vercel.

Live: https://patty-hello-world.vercel.app

## Development

Run locally:

```bash
npm run dev
```

Build:

```bash
npm run build
```

## MCP

This project includes:

- Vercel MCP: `https://mcp.vercel.com`
- Next DevTools MCP: `next-devtools-mcp@latest`

## Deployment

Production deploys from `main` through Vercel.
